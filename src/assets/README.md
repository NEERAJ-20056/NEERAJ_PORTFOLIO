# Assets Directory

This directory stores local media assets for the portfolio.

## Structure:
- `profile.jpg`: Place your profile photo here. If not provided or if the file fails to load, the portfolio automatically and gracefully renders an initials avatar ("RNC").
- `projects/`: Place optional project preview images here (e.g. `customer-segmentation.jpg`, `house-prices-prediction.jpg`).
- `certificates/`: Place optional certificate images/scans here.
